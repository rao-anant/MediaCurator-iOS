Xcode Shortcuts — Windows keyboard over RDP (MacinCloud)
Translation rule: ⌘→Win (Windows logo key), ⌥→Alt, ⌃→Ctrl, ⇧→Shift
Build / Run / Test
Action	Mac	Windows keys
Build	⌘B	Win+B
Run	⌘R	Win+R
Stop	⌘.	Win+.
Run tests	⌘U	Win+U
Clean build folder	⇧⌘K	Shift+Win+K
Build & analyze	⇧⌘B	Shift+Win+B

Top 5 for the port
Win+B — build
Win+R — run
Win+. — stop
Shift+Win+O — Open Quickly (jump between files fast)
Alt+Win+Enter — toggle SwiftUI canvas preview
RDP gotchas
Function keys (F6–F8) may need Fn held if your F-row defaults to media keys.
If a shortcut gets swallowed by Windows instead of reaching the Mac, set your RDP client to send keyboard shortcuts to the remote session (Microsoft Remote Desktop → session settings).
Copy/paste = Win+C / Win+V. Ensure Clipboard redirection is enabled in the RDP client.
Sources: MacinCloud support portal (support.macincloud.com); Microsoft Remote Desktop keyboard mapping docs.
